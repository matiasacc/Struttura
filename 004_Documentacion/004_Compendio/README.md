# 004_Compendio

Material de trabajo para incorporar el *Compendio de Cálculo Estructural II* (UNC FCEFyN, Massa-Giró, 2024) a Struttura.

* `PLAN_Compendio.md` — cómo se reparte el libro en el programa y en qué orden se hace.
* `ERRATAS_Y_DUDAS.md` — posibles erratas detectadas al leerlo (a confirmar con la cátedra).
* `resumenes/capNN_resumen.md` — notas por capítulo: fórmulas clave con página y ecuación, datos a cargar, propuesta de implementación, riesgos.
  Están escritas con palabras propias; el texto de referencia es el libro.
